# Vedang Asgaonkar

Personal website, built as a lightweight Jekyll site and published through GitHub Pages.

## Local development

Install the Ruby dependencies and start the development server:

```sh
bundle install
bundle exec jekyll serve
```

The site is available at `http://localhost:4000`. Content lives in the top-level Markdown files, essays in `_posts/`, shared templates in `_layouts/` and `_includes/`, and styles in `assets/css/site.css`.
